# ⚙️ Installation

Clone the repository https://github.com/myahtutkhaung2711/mya-htut-khaung-portfolio-V2.git

```bash
git clone 
```

Go to the project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
